<h1>Movie Ticket Website</h1>


<h2>Description</h2>
Designed and developed a responsive gaming website featuring an intuitive navigation bar with sections for Home, Categories, Subscription, Contact, Community, and Tournaments. The project focuses on creating a clean user interface and enhancing user experience through organized content and modern web design principles.
<br />
<ul>
<li>Developed a responsive gaming website with a clean and modern user interface.</li>
<li>Designed an intuitive navigation system for seamless user experience.</li>
<li>Implemented sections for Home, Categories, Subscription, Community, Contact, and Tournaments.</li>
<li>Focused on responsive design for desktop and mobile compatibility.</li>
<li>Applied modern web design principles to enhance usability and accessibility.</li>
<li>Strengthened front-end development skills through hands-on implementation.</li>
</ul>

<h2>Languages and Utilities Used</h2>

<ul>
  <li>HTML</li>
  <li>PHP</li>
  <li>CSS</li>
  <li>JAVASCRIPT</li>
  <li>MYSQL | PHPMYADMIN</li>
</ul>
